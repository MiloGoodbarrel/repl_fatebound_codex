---
name: Condition timer cadence
description: Defines when minute-based combat condition timers advance.
---

Timed conditions advance once when initiative completes a full cycle and the round counter increments. One minute equals ten rounds.

**Why:** The encounter clock represents six-second rounds, so decrementing on every creature turn would make durations depend on party size and expire too quickly.

**How to apply:** Any future duration, concentration, or encounter-clock feature should use the same round-rollover boundary unless the DM explicitly chooses a different timing rule.
