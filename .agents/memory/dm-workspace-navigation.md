The user wants a tabbed layout for all active features to make the app easier for the DM to use during play.

**Why:** The user reiterated that they had previously requested this and asked to make it a reality before publishing.

**How to apply:** Keep navigation available across campaign management, loot, roll tables, initiative, and sessions. Switching tools should not discard a live fight or current selections. Treat refresh persistence and private journal access as separate guarantees; navigation must not bypass unsaved-note guards or campaign authorization.
