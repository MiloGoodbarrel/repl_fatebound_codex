## Scope
The user's instruction for The Hollow Carnival was: “Add this module as a separate campaign, inject all NPCs those friendly and enemies, save the encounters. Leave out the pregen players.”

**Why:** The user requested a playable, separately owned module, not a replacement for existing campaigns or an imported player party.

**How to apply:** Keep this adventure's content campaign-scoped and additive. NPCs include named captives and optional townsfolk, not only the main cast. Do not import its pregenerated player characters.

## Source ambiguity and adaptation
The gate panel count is not specified; the starting group of two is an editable import assumption, not a printed encounter count. The carousel explicitly specifies one Stallion and two horses. Do not infer rescued-captive counts for Quill from reference-roster membership.

The source has no combat blocks for civilian NPCs or several background creatures. Civilian tracker statistics use an explicitly labelled commoner adaptation, not claimed module statistics; un-statted supernatural references must not silently become fabricated combat-ready enemies.

The narrative and player-handout captive names differ. In particular, Sara Mills and Little Sara are not established aliases. Preserve their separate references unless the user resolves them.

**Why:** The supplied PDF contradicts itself in places and leaves some details undefined. Silent reconciliation would create unsupported identities, combat statistics, or encounter assumptions.

**How to apply:** Label adaptations, preserve complete printed enemy rules, and retain uncertainty in module notes rather than inventing missing source details.
